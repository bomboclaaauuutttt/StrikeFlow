 * AUDIO FILES GUIDE
 * 
 * The audioManager.ts file expects audio files in this directory.
 * 
 * Optional audio files for sound effects:
 * - bell.mp3     : Plays on round/break transitions (lower pitch, deeper tone)
 * - blip.mp3     : Plays on countdown (higher pitch for attention)
 * 
 * If you want to add sound effects:
 * 1. Place .mp3 files in this directory
 * 2. Update audioManager.ts to reference them
 * 3. Restart the app
 * 
 * If you don't add audio files, the app will still work perfectly fine
 * with haptic feedback (vibration) alone.
 * 
 * Recommended audio sources:
 * - Freesound.org (Creative Commons sounds)
 * - Zapsplat.com (free sound effects)
 * - Generate from online tools like Bfxr or SFXR
 * 
 * Or download these free bell sounds:
 * - https://freesound.org/search/?q=bell+sound
 * - https://freesound.org/search/?q=ding+sound
