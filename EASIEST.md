2. Timer opens in your browser

## Features

### Main Timer Screen
- **Large timer display** (MM:SS)
- **START / PAUSE / RESET** buttons
- **Settings button** (⚙️)

### Task Spar Mode
- **20+ training tasks**
- **Random each round**
- **No repeats in a row**
- **3-second countdown** before each round
- **Task visible** during training

### Settings
- **3 Quick Presets:**
  - K1: 3 rounds × 3 min
  - Muay Thai: 5 rounds × 3 min
  - Conditioning: 10 rounds × 1 min
- **Custom Settings:**
  - Adjust round time
  - Adjust break time
  - Set number of rounds
  - Toggle Task Spar ON/OFF
