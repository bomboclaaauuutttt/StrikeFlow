# 🎯 Super Simple - Just 2 Clicks!

## For Windows Users 🪟

### Step 1: Find and Open

In the StrikeFlow folder, find the file called **`START.bat`**

It looks like a white document with a gear icon or bat symbol.

Double-click it.

### Step 2: That's It!

A command window will pop up. You'll see:
```
========================================
   STRIKEFLOW - Muay Thai Timer
========================================

Your app is starting!

Instructions:
  1. On iPhone: Point camera at QR code, tap the link
  2. On Android: Open Expo Go, scan the QR code

Keep this window open while using the app.
Close this window to stop the app.

========================================
```

Below that you'll see a QR code appear.

### Step 3: Scan with Phone

**On iPhone:**
- Point your camera at the QR code in the window
- Tap the notification that appears
- Tap to open in Expo Go
- Wait 30-60 seconds for app to load

**On Android:**
- Open the Expo Go app
- Tap "Scan QR Code"
- Point at the QR code in the window
- App loads automatically

### Step 4: Done! 🎉

Your timer app is now running on your phone!

## If It Doesn't Work

### "File not found"
- Make sure you're in the correct folder (StrikeFlow)
- File should be named exactly `START.bat` or `START.sh`

### "Node.js not installed"
- The script will tell you
- Go to https://nodejs.org/
- Download and install
- Restart your computer
- Try again

### Nothing happens when I double-click
- **Windows**: Right-click the file → "Run as administrator"
- **Mac/Linux**: Right-click → "Open with" → Terminal

### Still stuck?
See [GETTING_STARTED.md](GETTING_STARTED.md) for more detailed help.

## What's Happening Behind the Scenes

The script automatically:
1. ✅ Checks if Node.js is installed
2. ✅ Installs dependencies (first time only, takes 2-5 min)
3. ✅ Starts the development server
4. ✅ Shows you the QR code
5. ✅ Keeps the server running

No commands. No typing. Just one double-click!
