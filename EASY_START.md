# 🚀 EASIEST WAY TO START

## Option 1: Windows (EASIEST) ✅

**Just double-click:** `START.bat`

That's it! The app will:
1. Check for Node.js
2. Install dependencies automatically
3. Start the server
4. Show you the QR code

Then scan with your phone and you're done!

---

## Option 2: Mac/Linux

**Make the script executable:**
```bash
chmod +x START.sh
```

**Then double-click:** `START.sh`

Or run in terminal:
```bash
bash START.sh
```

---

## What Happens When You Run It

```
1. Script starts
2. Checks if Node.js is installed
3. If first time: installs dependencies (2-5 minutes)
4. Displays QR code in terminal
5. Keep window open
6. Scan QR code with your phone
7. App loads on phone
8. Close window when done training
```

---

## If Something Goes Wrong

### "Node.js is not installed"
- Go to https://nodejs.org/
- Download and install the LTS version
- Restart your computer
- Try again

### Script won't run
- **Windows**: Right-click START.bat → "Run as administrator"
- **Mac/Linux**: Try opening terminal and running `bash START.sh`

### Still stuck?
- See [GETTING_STARTED.md](GETTING_STARTED.md) for detailed help

---

## That's All!

No terminal commands needed. No npm commands needed. Just:
1. Double-click START.bat (Windows) or START.sh (Mac/Linux)
2. Scan the QR code
3. Train! 🥊
